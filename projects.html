CyberSOC - Security Operations Center Dashboard

CyberSOC is an interactive cybersecurity dashboard designed to simulate the activities of a Security Operations Center (SOC). The application demonstrates security alert monitoring, threat investigation, incident response, and security activity logging. It includes simulated cybersecurity threats such as brute force attacks, suspicious login attempts, phishing, and ransomware indicators. This project strengthens my practical understanding of SOC operations and cybersecurity incident management.

Technologies Used: HTML, CSS, JavaScript

Project Features: Security Alerts, Network Monitoring, Incident Response, Threat Severity Filtering, and Security Activity Logs.
