# Jemilat Olatunji — Redesigned Portfolio

Responsive, dark-navy cybersecurity portfolio.

## Preview
Open `index.html` with VS Code Live Server. All four pages use the same `style.css` and `script.js`.

## Deploy to existing GitHub repository
1. Back up your current `My-Portfolio` folder.
2. Copy the **contents** of this redesigned folder into your existing `My-Portfolio` folder (replace files when asked). Do not copy a `.git` folder; none is included here.
3. Preview all pages in Live Server, including at mobile width.
4. In GitHub Desktop, commit the changed files and Push origin.

Your portrait, certificates, contact information and project links are preserved.
